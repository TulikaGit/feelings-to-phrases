# feelings-to-phrases
Transforming moods into motivational words through C programming 
A beginner-friendly C project that prints motivational quotes based on the user's mood.  
This project demonstrates user input, string comparison, and conditional statements in C.

## Features
- User enters mood (happy, sad, stressed, excited)
- Program prints a motivational quote based on mood
- Default quote for unknown moods

## How to Run
1. Compile using: `gcc mood_quotes.c -o mood_quotes`
2. Run with: `./mood_quotes`

## Sample Output
Enter your mood (happy, sad, stressed, excited): happy  
Quote: Keep smiling, because life is a beautiful thing!
